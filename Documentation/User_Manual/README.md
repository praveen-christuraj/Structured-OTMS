# OTMS User Manual (Page-wise Drafts)

This folder contains **page-by-page** draft documentation for the OTMS application.
It is written so you can **copy/paste sections** into a final user manual.

## How to use these drafts

- Start with `Documentation/User_Manual/INDEX.md` to find the page you want.
- Each page document follows the same structure (Purpose, Access, Steps, Tips, Troubleshooting).
- Where a topic is already documented in detail elsewhere, the page doc links to the existing file in `Documentation/`.

## Notes

- **Active Location:** Most operational pages work on the currently selected **Active Location** (set on **Home**).
- **Head Office (HO):** If a location is marked as **Head Office**, it is treated as *non-operational* (no tanks/assets on-site). Users should switch the Active Location to an operating terminal for entry pages.
- **Audit Log & Time:** Audit events are stored in **UTC** and displayed in the UI as **Nigeria Time (WAT, UTC+1)** where available.

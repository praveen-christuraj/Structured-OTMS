# Locations and Head Office (HO)

## Location types

### Operating Location
- Has physical assets (e.g., tanks) and produces transactions.
- Used for day-to-day entries and operational reporting.

### Head Office (HO)
- Administrative location that does **not** hold physical tanks/assets.
- HO can have its own dashboards/reports/customizations, but operational entry pages require switching the Active Location to an operating terminal.

## How to mark a location as Head Office

1. Go to `Manage Locations`
2. Edit the location
3. Enable **Head Office**
4. Save

## How HO users work day-to-day

1. Go to `Home`
2. Use **Select Active Location** to switch to the operating location you want to view
3. Navigate to the required operational page (Tank Transactions, YADE, etc.)

If the Active Location is HO, asset-dependent pages will show a message asking you to switch to an operating location.

## What is scoped per location

- Dashboard configuration and widgets
- Location Settings (page visibility, operations catalogs, tab visibility)
- Page Customization definitions (dynamic tables and custom tabs)
- Stock Analysis tabs (analytics configuration)

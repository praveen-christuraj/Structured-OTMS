# Login History

## Purpose

Login History shows recent login attempts, including:
- success vs failed logins
- source IP and location (where available)
- device/browser details (where available)

## Who can access

- Typically admin roles and managers (per policy).

## How to use

1. Open `Login History`
2. Filter by user, time period, status, and 2FA usage
3. Review recent attempts

## What to do when you see suspicious activity

- If you see unknown IP/device attempts for your account:
  - change your password
  - enable 2FA (or regenerate backup codes)
  - inform Admin-IT / Admin-Operations

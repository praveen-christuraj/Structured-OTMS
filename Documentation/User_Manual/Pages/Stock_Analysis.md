# Stock Analysis

## Purpose

Stock Analysis shows analytics tabs configured for the Active Location, including:
- tables
- charts
- KPI widgets

## Who can access

- Operational roles and managers when enabled for the location.

## How to use

1. Select Active Location on `Home`
2. Open `Stock Analysis`
3. Choose the desired tab and apply any filters

## Configuration

Tabs are defined in `Stock Analysis Customization`.

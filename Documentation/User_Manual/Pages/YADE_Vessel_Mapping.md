# YADE–Vessel Mapping

## Purpose

Manage and review mapping between YADE voyages and vessel operations (as configured in your deployment).

## Who can access

- Operational roles when enabled for the location.

## How to use (high-level)

1. Select Active Location on `Home`
2. Open `YADE-Vessel Mapping`
3. Apply date/location filters
4. Review the mapping and export if required

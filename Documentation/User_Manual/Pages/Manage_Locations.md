# Manage Locations

## Purpose

Create and maintain the list of locations (terminals) used across OTMS.

## Who can access

- Admin roles with management access.

## Create a new location

1. Open `Manage Locations`
2. Enter:
   - Location Name
   - Short Code
   - Address (optional)
3. (Optional) enable **Head Office (no assets)** if this is an HO location
4. Click **Create Location**

## Edit a location

1. In the locations table, click **Edit**
2. Update name/code/address/status and save
3. Use the **Head Office** toggle to mark one location as HO

## Delete a location

Deletion is soft-delete (marks the location inactive).

## Notes (Head Office)

- A Head Office location is intended for dashboards/reports and cross-location viewing.
- Asset and entry pages should be used with an operating location selected as Active Location.

## Audit logging

- Create/update/delete location actions are recorded in the audit log.

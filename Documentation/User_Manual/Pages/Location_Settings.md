# Location Settings

## Purpose

Location Settings controls per-location behavior, including:
- which pages are enabled for the location (Page Access)
- which Tank Transactions tabs are visible (Tab visibility)
- operations catalogs that drive dropdowns (destination, berths, etc.)

## Who can access

- Admin roles with management access.

## Page Access (visibility)

1. Open `Location Settings`
2. Confirm the Active Location is correct
3. Enable/disable pages for that location

If a page is disabled here, it may not appear in the sidebar or may refuse to render for that location.

## Tank Transactions tab visibility

Use the Tank Transactions (Tabs) section to turn individual tabs on/off:
- Tank Entry
- Meter Records
- Condensate Records
- Produced Water Records
- Production (if enabled)

## Operations catalogs (dropdown sources)

Configure standardized dropdown options used by entry pages (examples):
- destinations
- loading berths
- cargo types

## Audit logging

- Configuration changes are recorded in the audit log.

# Back Data (Back Data Upload)

## Purpose

Back Data Upload allows administrators to import historical data into database tables using CSV/XLSX templates.

## Who can access

- Admin-IT and Admin-Operations.

## How to use (step-by-step)

1. Select Active Location on `Home` (used to auto-fill `location_id` where present)
2. Open `Back Data`
3. Select the target table
4. Download the CSV template and fill it with data
5. Upload the CSV/XLSX file
6. Confirm column validation passes
7. Import to database

## Tips

- Column names must match exactly.
- If the table has `location_id`, it is auto-filled from the Active Location.

# Tank Transactions View (Legacy / Optional)

## Purpose

This page is an alternative, read-only viewer for tank transactions with date range filtering and export options.

## Notes

- Depending on your current sidebar configuration, this page may not be linked directly.
- The recommended viewer for most users is `View Transactions`, which consolidates transaction viewing across modules.

## How to use

1. Select Active Location on `Home`
2. Open the Tank Transactions view (if available in your deployment)
3. Set the date range
4. Export to CSV/XLSX/PDF (where available)

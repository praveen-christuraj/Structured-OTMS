# Export Operations

## Purpose

Export Operations supports export process tracking, stage progress, due dates, and export-related reporting for the Active Location (as configured).

## Who can access

- Users granted Export Operations access (policy-based; often Admin-Operations and explicitly enabled users).

## How to use (high-level)

1. Select Active Location on `Home`
2. Open `Export Operations`
3. Select an export terminal / process
4. Update required stage fields and statuses
5. Save and export reports if needed

# 2FA Settings

## Purpose

This page provides a guided flow for enabling, verifying, and managing Two-Factor Authentication (2FA).

## Who can access

- All signed-in users.

## Enable 2FA (step-by-step)

1. Open `2FA Settings`
2. Click **Enable 2FA**
3. Scan the QR code using an authenticator app (Microsoft Authenticator / Google Authenticator / Authy)
4. Enter the 6-digit code to verify
5. Save your backup codes (download and store securely)

## Manage 2FA (when already enabled)

- View backup codes
- Regenerate backup codes
- Disable 2FA (only if your account is not forced/mandatory)

## Troubleshooting

- If you lose your device, use **backup codes**.
- If you cannot recover, request help from an administrator.

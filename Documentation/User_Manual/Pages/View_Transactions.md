# View Transactions

## Purpose

View Transactions is a read-only (or controlled-edit) viewer for transactions across modules, with filters and export options.

## Who can access

- Operational roles and managers (per policy and location settings).

## How to use

1. Select Active Location on `Home`
2. Open `View Transactions`
3. Choose the transaction type (tank/yade/tanker/etc. depending on build)
4. Apply filters (date range, search)
5. Export as needed

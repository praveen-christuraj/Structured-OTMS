# Vessel Operations

## Purpose

Capture vessel-related operational records for the Active Location (vessels, mooring/operations steps, etc.).

## Who can access

- Operational roles when enabled for the location.

## Before you start

- Ensure vessels exist in `Asset Management` and are assigned to the location where required.

## How to use (high-level)

1. Select Active Location on `Home`
2. Open `Vessel Operations`
3. Create/update vessel operation records as per workflow

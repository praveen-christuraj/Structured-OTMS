# YADE Transactions

## Purpose

Capture YADE voyage transactions for the Active Location, typically including:
- voyage creation / editing
- stage-by-stage details
- seals and measurements
- voyage list view

## Who can access

- Operational roles when enabled for the location (`Location Settings → Page Access`).

## How to use (typical)

1. Select Active Location on `Home`
2. Open `YADE Transactions`
3. Use **Entry / Edit** to create or update a voyage
4. Use **Voyages List** to review existing voyages

## Troubleshooting

- If the page shows “disabled for this location”, enable it in `Location Settings`.

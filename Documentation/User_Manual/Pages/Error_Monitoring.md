# Error Monitoring

## Purpose

Error Monitoring is an admin dashboard to track:
- error tasks raised by the system
- pending vs resolved errors
- basic health indicators (failed audit actions, total actions)

## Who can access

- Admin-IT and Admin-Operations.

## How to use

1. Open `Error Monitoring`
2. Select the time range (24 hours / 7 days / 30 days / all time)
3. Review:
   - error summary
   - severity breakdown
   - recent error tasks
4. Resolve or mark tasks in progress (where available)

## Tips

- Use this page together with `Audit Log` to understand what failed and when.

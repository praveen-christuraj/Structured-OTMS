# FSO-Operations

## Purpose

FSO-Operations supports floating storage operations and related reporting for the Active Location.

## Who can access

- Operational roles when enabled for the location.

## Before you start

- Ensure FSO(s) exist and are assigned to the Active Location (where required).

## How to use (high-level)

1. Select Active Location on `Home`
2. Open `FSO-Operations`
3. Use the page workflow to capture and review FSO operations

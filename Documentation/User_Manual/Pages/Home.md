# Home

## Purpose

Home is the landing page after login. It is used to:
- select the **Active Location**
- view the dashboard for the selected location
- quickly move to other pages

## Who can access

- All signed-in users (content depends on role).

## Key concept: Active Location

Most pages use the Active Location to decide:
- which assets and transactions to load
- which pages are visible (Location Settings → Page Access)
- which analytics tabs and dashboards to show

## How to use (step-by-step)

1. Open `Home`
2. Under **Select Active Location**, choose the location you want to work on
3. Confirm the dashboard header shows the correct location
4. Navigate to operational pages (Tank/YADE/Tanker/etc.) for that same Active Location

## Head Office users

If your assigned location is marked **Head Office**:
- you can switch Active Location to any operating terminal for viewing reports/transactions
- asset-dependent entry pages will prompt you to switch to an operating location

## Audit logging

- Switching Active Location is recorded in the audit log.

## Troubleshooting

- **No active location selected:** choose one on Home.
- **Page missing from sidebar:** check `Location Settings` page access for the location.

# Services

## Purpose

Raise internal service requests (IT/Operations support) and track their status.

## Who can access

- All signed-in users can raise service requests.
- Admin users can view a broader list depending on policy.

## Raise a service request

1. Open `Services`
2. Go to **Service Request**
3. Select location and service type
4. Add description and contact details
5. Submit

## Check request status

1. Open `Services`
2. Go to **Status**
3. View your requests (or all requests if admin)

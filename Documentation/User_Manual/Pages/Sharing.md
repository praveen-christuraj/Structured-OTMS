# Sharing

## Purpose

Share files within OTMS:
- upload a file with optional remarks
- view and download shared files
- admins can delete shared files

## Who can access

- All signed-in users can upload and view shared files (scope depends on policy).
- Admin users can view “All Locations” and delete files.

## Upload a file

1. Open `Sharing`
2. Go to **Upload**
3. Select a file and add remarks (optional)
4. Click **Share**

## Download a shared file

1. Open `Sharing`
2. Go to **Shared Files**
3. Click **Download**

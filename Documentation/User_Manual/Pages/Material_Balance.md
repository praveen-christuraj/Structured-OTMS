# Material Balance

## Purpose

Compute and present material balance sheets for the Active Location.

## Who can access

- Operational roles and managers when enabled for the location.

## Before you start

- Ensure underlying transactions exist (tank entries, OTR sources, etc. depending on configuration).

## How to use (high-level)

1. Select Active Location on `Home`
2. Open `Material Balance`
3. Choose date range / period
4. Review results and export if required

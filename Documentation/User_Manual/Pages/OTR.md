# OTR (Out-Turn Report / Operational Tank Reconciliation)

## Purpose

OTR provides operational reconciliation views and calculations for the Active Location.

## Who can access

- Operational roles when enabled for the location.

## How to use (high-level)

1. Select Active Location on `Home`
2. Open `OTR`
3. Apply date filters and run the OTR view
4. Export as required

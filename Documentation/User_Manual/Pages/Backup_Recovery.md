# Backup & Recovery

## Purpose

Backup & Recovery is an admin page used to:
- create database backups
- restore from backups
- delete and clean up old backups
- export all data for a specific location (ZIP export)

## Who can access

- Admin-IT and Admin-Operations.

## Create a backup

1. Open `Backup & Recovery`
2. Go to **Create Backup**
3. Enter a description
4. Create the backup

## Restore from backup

1. Go to **Backups**
2. Select a backup
3. Type `RESTORE` to confirm
4. Restore

## Important note

Restoring replaces the current database. Always confirm you have the correct backup.

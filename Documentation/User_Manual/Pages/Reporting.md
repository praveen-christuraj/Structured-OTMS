# Reporting

## Purpose

Reporting is the page where users run/view configured reports.

## Who can access

- Operational roles and managers when enabled for the location.

## How to use (typical)

1. Select Active Location on `Home`
2. Open `Reporting`
3. Select the report you want to run
4. Apply filters (date, location, etc.)
5. Generate and export if needed

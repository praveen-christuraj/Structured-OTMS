# YADE Tracking

## Purpose

YADE Tracking provides a customizable tracking view across YADE voyage milestones (e.g., departure vs arrival comparisons).

## Who can access

- Operational roles when enabled for the location.

## How it is configured

YADE Tracking is driven by per-location configuration created in `Page Customization`:
- tables/titles
- columns mapped to source fields
- filter behavior

## How to use

1. Select Active Location on `Home`
2. Open `YADE Tracking`
3. Choose the configured table/view
4. Apply filters and review the tracking output

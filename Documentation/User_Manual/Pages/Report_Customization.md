# Report Customization

## Purpose

Create and manage configurable reports, including:
- choosing a data source (including custom tab tables)
- selecting columns and filters
- grouping and sorting (where supported)
- saving report definitions for later use

## Who can access

- Admin roles (per policy).

## How to use (high level)

1. Choose the Active Location (if report definitions are location-scoped in your setup)
2. Open `Report Customization`
3. Create or edit a report definition
4. Save
5. Open `Reporting` to run/view the report

## Tip

If you created a Custom Tab in `Page Customization`, its table should appear as a data source for reports.

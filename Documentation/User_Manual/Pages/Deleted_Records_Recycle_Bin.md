# Deleted Records (Recycle Bin)

## Purpose

Deleted Records is a recovery page for records that were deleted (archived) through the application.

## Who can access

- Typically admin roles (per policy).

## How to use

1. Open `Deleted Records`
2. Filter or search for the item you need
3. Restore the record (if supported)

## Notes

- Not every delete action is permanent; many deletes are routed to the recycle bin for safety.
- Use `Audit Log` to see who deleted an item and when.

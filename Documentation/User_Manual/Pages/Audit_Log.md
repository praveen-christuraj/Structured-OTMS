# Audit Log

## Purpose

Audit Log shows security and operational events recorded by OTMS, such as:
- logins, logouts, session expiry
- create/update/delete actions on records
- configuration changes
- exports (where implemented)
- error events (where implemented)

## Who can access

- Admin roles and managers (per policy).

## How to use

1. Open `Audit Log`
2. Choose a date range (last 24 hours / 7 days / 30 days / all)
3. (Optional) filter to “only my actions”
4. Search the table for keywords (username, resource type, record id, etc.)

## Time display

- Shown in **Nigeria Time (WAT, UTC+1)** when timezone utilities are available.

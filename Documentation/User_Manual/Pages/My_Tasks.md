# My Tasks

## Purpose

My Tasks is a task inbox for operational workflow and approvals. Typical tasks include:
- deletion approval requests
- password reset requests (for admins)
- system error alerts (for admins)
- service requests (depending on configuration)

## Who can access

- Signed-in users (tasks shown depend on role and assignment).

## How to use

1. Open `My Tasks`
2. Use filters (status/type) to find what you need
3. Open a task to view details
4. Complete the task action (approve/reject/resolve) where permitted

## Notes

- Operators may raise deletion requests which are routed to supervisors.
- Admins see broader task types (IT/system/admin-operations).

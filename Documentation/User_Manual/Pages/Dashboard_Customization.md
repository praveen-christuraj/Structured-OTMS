# Dashboard Customization

## Purpose

Configure the Home dashboard experience for a location:
- layout and sections
- summary cards
- charts / visuals
- tank visuals mapping (when tanks exist)
- styling controls (colors, gradients, header settings)

## Who can access

- Admin roles (per policy).

## How to use (typical flow)

1. Set the Active Location on `Home`
2. Open `Dashboard Customization`
3. Adjust sections/widgets for that location
4. Save and return to `Home` to verify

## Head Office behavior

If the Active Location is **Head Office**, tank-specific dashboard visuals may be unavailable because HO has no tanks.

# Profile Settings

## Purpose

Manage your own account settings:
- change password
- set up or manage 2FA (depending on policy)
- view password expiry status

## Who can access

- All signed-in users.

## Change password (typical steps)

1. Open `Profile Settings`
2. Enter current password
3. Enter new password and confirm
4. Save

## 2FA management

Depending on policy, you can:
- enable 2FA
- disable 2FA (if not mandatory)
- generate and store backup codes

## Audit logging

- Password and 2FA changes are logged in the audit trail.

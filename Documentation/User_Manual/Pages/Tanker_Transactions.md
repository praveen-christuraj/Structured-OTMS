# Tanker Transactions

## Purpose

Record road tanker dispatch and related details for the Active Location (tickets, seals, volumes, etc.).

## Who can access

- Operational roles when enabled for the location.

## Before you start

1. Select Active Location on `Home`
2. Ensure tankers exist in `Asset Management → Tankers`
3. Ensure the page is enabled for the location (`Location Settings → Page Access`)

## Main workflow (typical)

1. Open `Tanker Transactions`
2. Complete the Tanker Dispatch form fields
3. Save the transaction

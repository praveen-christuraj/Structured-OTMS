OTMS-Rebuild — Pages Documentation

This document describes every page module under `app_pages/`: purpose, entry function, access rules, core UI/data behavior, and important configuration dependencies. Line references use the pattern `file_path:line_number` for quick navigation.

Home
- Entry: `app_pages/home.py:279` → `render_home_page(active_location_id, user)`
- Purpose: Landing dashboard for location selection, user overview, and quick navigation.
- Access: All signed-in roles; content adapts by `user.role` and active location.
- Key: Displays location picker, session info, and summaries.

Login
- Entry: `app_pages/login.py:11` → `render_login_page()`
- Purpose: Sign-in UI with session bootstrap.
- Notes: Captures client IP and user-agent (integrated elsewhere for 2FA/Login History).

Login History
- Entry: `app_pages/login_history.py:33` → `render_login_history_page(...)`
- Purpose: Shows recent login attempts with IP and geolocation details.
- Access: Admin/Managers; reads from audit/auth models.

- Access: All signed-in users; sensitive actions gated.

Location Settings
- Entry: `app_pages/location_settings.py:38` → `render_location_settings_page(active_location_id, user)`
- Purpose: Per-location configuration:
  - Page Access toggles (e.g., Tank, YADE, OTR, Vessel, FSO, Reports, YADE Tracking).

Page Customization
- Entry: `app_pages/page_customization.py` → top-level function `render_page_customization(user)` (near file start)
- Purpose: Configure per-location page sections and dynamic tables:
  - Condensate Meter definitions.
  - Produced Water dynamic table (columns, types, formulas).
  - Production dynamic table (columns, types, formulas).
  - Meter Records config.
  - Custom Tabs management for Tank/Tanker pages.
  - YADE Tracking customization (tables, columns mapped to source fields, filters, titles).
- Dependencies: `location_config.py` (`get_page_section_config`, `set_page_section_config`, `get_dynamic_table_def`, `set_dynamic_table_def`, custom tabs APIs).

Yade Tracking
- Entry: `app_pages/yade_tracking.py:111` → `render_yade_tracking_page(active_location_id, user)`
- Purpose: Track Voyage NSV across Jetty Departure vs Agge Arrival; fully customizable:
  - Admin defines tables, titles, columns mapped to source fields, and filters under Page Customization.
  - Page reads config and renders per-table filters and columns.
- Visibility: Controlled via `Location Settings → Page Access → 📍 YADE Tracking`.
- Sources: Location tokens matched for `ASEMOKU`, `NDONI`, `AGGE`.

Notes on Access & Visibility
- Operational pages appear based on `location_config.get_location_page_visibility` flags per location.
- Management pages require `PermissionManager.can_access_management_pages(user)`.
- Most pages gate content with `PermissionManager.can_access_operational_pages(user)` and `AuthManager.can_access_location(user, location_id)`.
